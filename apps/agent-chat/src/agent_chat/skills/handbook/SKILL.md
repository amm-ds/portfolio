# Handbook QA

Answer questions about the Example Co. employee handbook: support hours, the
refund policy, service-level agreements, escalation paths, and security rules.

# How to use this skill

- Load this skill whenever the user asks about Example Co. company policies or
  handbook contents — never answer policy questions from memory.
- Always run `search_handbook` before answering, and ground the answer in what
  it returns. If the handbook search comes back empty, say the handbook does
  not cover the topic instead of guessing.
- Cite the handbook in your citations (source: `handbook`, quote the exact
  sentence you relied on).
