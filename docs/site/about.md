# About

**Alejandro Mérida Maroto (amm-ds)** — Data Scientist & ML Engineer.

I build end-to-end systems: data engineering, classical ML, deep learning, and
agentic AI — with the engineering artifacts around the code (decision records,
reproducible pipelines, evaluation harnesses, SLOs, runbooks) that make systems
operable, not just trainable.

This repository doubles as the public portfolio and the project showcase:
each pipeline reproduces from a clean clone (`make setup`, then `uv run dvc
repro` inside its project directory) and is served by the
[showcase app](../index.md#quick-start).

## Services

Eight offerings
each backed by a public case study (details on the
[Services](services.md) page):

- **Agentic AI & LLM systems** — RAG, structured tool use, eval harnesses,
  cost/latency budgets with fallback chains (see Projects 01, 09).
- **Machine learning** — leakage-proof backtests, calibrated models,
  business-cost threshold analysis, pinned CI evaluation (see Projects 02,
  05, 10).
- **Optimization** — routing, scheduling, allocation against benchmark
  instances, with the optimality gap stated (see Project 06).
- **Data engineering** — versioned, DQ-gated pipelines over large
  open/commercial data, plus CI eval gates and drift checks (see Projects 07,
  11).
- **MLOps** — CI evaluation gates, Docker + uv
  environments, runbooks (see Projects 05, 08).
- **Interactive dashboards** — decision tools over live endpoints with
  parity-tested payloads (see the showcase app demos).
- **Full-stack engineering** — typed APIs, React frontends, and
  one-command deployments that run from a clean clone (see Project 07 and
  the showcase app).
- **APIs & model serving** — versioned endpoints with explicit contracts,
  measured latency/throughput, and the typed API, web UI and deployment
  around them wired into one product slice (see Projects 08, 13).
