# Projects

Thirteen showcases across agentic AI, classical ML, deep learning,
optimization, model serving, decision science, and large-scale open-data
engineering. Each
page links the problem, the design record, and the evaluation artifacts; the
same case studies render with interactive figures in the showcase app when it
runs locally (`make docker-up` → http://localhost:8000, Projects section).
Public deployment status: [deploy/DEPLOY.md](https://github.com/amm-ds/portfolio/blob/main/deploy/DEPLOY.md).
